# PriceMCP WebMCP demo narration

## Scene 1 — live site

PriceMCP answers a simple question: when an agent finds a price, can a person
actually trust it? Let me show you the browser-native version. This is the live
site, and the browser gets purpose-built tools directly from the page—no screen
scraping and no guessing what the interface means.

## Scene 2 — tools discovered

Chrome finds three WebMCP tools. They are deliberately read-only. An agent can
find the best price, inspect the underlying evidence, or run this disclosed
flight example. It cannot buy anything, reserve anything, or quietly change
data.

## Scene 3 — agent call

I'll ask it to run the flight example. The browser calls PriceMCP through
WebMCP, with a real structured request. We use a synthetic itinerary here so
the demo stays reproducible; it is clearly marked non-bookable everywhere it
appears.

## Scene 4 — shared result

Now watch the handoff. The agent gets structured evidence, and the same result
appears on the page for the person to review. United ranks first at six hundred
twelve dollars, but the useful part is everything around that number: the
conditions, alternatives, and the reason it won.

## Scene 5 — evidence layer

Live product searches work the same way. PriceMCP resolves the exact variant,
then checks seller trust, availability, membership requirements, freshness, and
source links before naming a winner. The point is not to automate the purchase.
It is to let an agent do the tedious comparison work while the person sees the
same evidence and stays in control.
